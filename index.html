SenseCAP D1 Hubitat Dashboard

Flash the firmware directly from your browser — no software to install.

Your browser can't do this. Please open this page in Chrome or Microsoft Edge on a desktop or laptop computer. This page needs to be served over HTTPS (or opened from localhost) for the browser to allow a USB connection.

Before you start

  • Use Chrome or Edge on Windows, macOS, Linux, or ChromeOS — this uses the Web Serial API, which Safari and Firefox don't support, and it does not work on phones or tablets.
  • Connect the SenseCAP D1 to your computer with a USB cable that supports data, not just charging.
  • Close any other program that might be using the device's serial port (Arduino IDE, a terminal, another browser tab already connected to it, etc.).
  • If your operating system doesn't already have a driver for the board's USB-to-serial chip (commonly a CP210x or CH34x/CH9102 family chip depending on the exact unit), install the matching driver first, then reconnect the cable.

How to flash

  1. Click Connect device & install above.
  2. Your browser will show a list of serial/COM ports — pick the one for the D1 and click Connect.
  3. Click Install in the dialog that appears.
  4. You'll be asked whether to erase the device first. Choose No if you're updating a D1 that's already configured — this keeps your Wi-Fi and Hubitat setup and only updates the firmware itself, taking about 30–60 seconds. Choose Yes only for a brand-new device or if you deliberately want to wipe an existing one.
  5. When it finishes, click Next/Close. The D1 will reboot on its own.
Read the erase prompt carefully. This tool can't automatically detect whether your D1 already has this firmware installed, so it always asks. Choosing to erase wipes everything, including your saved Wi-Fi credentials and Hubitat configuration — you'll need to go through first-time setup again afterward. When in doubt on an existing device, choose No.

First-time setup (new / factory D1)

If this is a brand-new device with nothing configured yet, after flashing it will boot into its own Wi-Fi setup access point. Connect to that from your phone or computer, give it your home Wi-Fi details, then install the SenseCap D1 Config app on your Hubitat hub and enter the D1's local IP address there to start pushing your dashboard to it.

Having trouble?

  • No ports show up / "Connect device" does nothing noticeable — try a different USB cable or port, and make sure no other program has the port open.
  • Install fails partway through — reconnect the cable, refresh this page, and try again. Holding the board's reset button briefly before clicking Connect can also help on some units.
  • It flashed, but nothing shows on screen — give it a minute; the first boot after a flash can take a little longer while it reads its saved configuration.
